# khgn-inc.org

The public website of **Kentucky History and Genealogy Network, Inc.** (KHGN, Inc.), a 501(c)(3) nonprofit.

Live site: https://khgn-inc.org

## What's here

- **County Hubs:** a page for each of Kentucky's 120 counties, in the `counties` folder, with the directory at `socialmedia.html`
- **The Trailhead:** free public training, starting at `game-portal.html`, including the Tipple Trial, Flagging and Welcoming, the Proving Your Claim guides, the Record Field Guides, and the story trails
- **Volunteer pages:** `get-involved.html`, `training.html`, `volunteer-form.html`, and the privacy notice, `volunteer-privacy.html`

## Shared files

Several files serve every page at once. Edit them once, and the whole site updates:

- `khgn-nav.js`: the site menu and the disclaimer footer, also used by the private training site
- `khgn-path.js`: the "Your path" marker on the training pages
- `khgn-ticker.js`: the Trailhead ticker
- `khgn-county-ticker.js`, `khgn-county-obits.js`, and `khgn-county-about.js`: the county page ticker, obituaries, and "At a Glance" banner, which read text files kept in each county's folder
- `ticker-statewide.txt`: the statewide ticker list
- `khgn-age-gate.js`: the age check for the Trailhead pages

## Notes

- Private volunteer training lives in a separate private repository and is not part of this site.
- Draft Board documents and other private materials should never be uploaded here, since this repository is public.
- Questions about privacy: privacy@khgn-inc.org
